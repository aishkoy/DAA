Binary Search

1. Problem
Дан отсортированный массив nums и число target. Нужно найти индекс target в массиве или вернуть -1, если его там нет.

2. Approach
Заводим переменные left, right, middleIdx и middleNumber. left в начале равен 0, right равен индексу последнего элемента.
1) middleIdx считаем как середину между left и right, middleNumber = nums[middleIdx].
2) Если middleNumber равен target, возвращаем middleIdx.
3) Если target больше середины, сдвигаем left = middleIdx + 1, если меньше, то right = middleIdx. Так область поиска каждый раз уменьшается вдвое, и повторяем с шага 1.
4) Отдельно проверяем случаи, когда между left и right остался 1 или 2 элемента: проверяем их напрямую и возвращаем индекс или -1.

Tracing
nums = [-1, 0, 3, 5, 9, 12], target = 9
Итерация 1: left = 0, right = 5, middleIdx = 2, middleNumber = 3. 9 > 3, поэтому left = 3.
Итерация 2: left = 3, right = 5, middleIdx = 4, middleNumber = 9. 9 == 9, возвращаем 4.

Challenges
Так как right сдвигается на middleIdx, а не на middleIdx - 1, без отдельных проверок на 1 и 2 элемента границы могли перестать сдвигаться и цикл не заканчивался бы.

3. Time Complexity
Time Complexity: O(log n)

В худшем случае target найдётся в самый последний момент, когда в области поиска останется 2 элемента. Каждая итерация отрезает половину массива. Пусть k - номер итерации, n - размер массива:
после 1 итерации остаётся n/2
после 2 итераций n/4 = n/(2^2)
после 3 итераций n/8 = n/(2^3)
после k итераций n/(2^k)

Алгоритм закончится, когда n/(2^k) = 2. Берём log2 от обеих частей и пользуемся формулой log a - log b = log(a/b):
log2 n - log2(2^k) = 1
log2 n = 1 + k
Единицу можно отбросить, получается k = log2 n.

4. Space Complexity
Space Complexity: O(1)

Нужны только 4 переменные, дополнительная память не зависит от размера массива.

5. Reflection / Improvement
O(log n) - лучшая возможная сложность, но реализацию можно упростить. Если писать цикл while (left <= right) и сдвигать right = middle - 1, то отдельные проверки на 1 и 2 элемента не нужны: когда остаётся один элемент, right просто перескакивает за left и цикл заканчивается.
