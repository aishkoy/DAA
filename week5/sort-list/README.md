Sort List

1. Problem
Дан односвязный список из n узлов. Нужно вернуть его отсортированным по возрастанию.

2. Approach
Та же идея merge sort, что и с массивом, но с отличиями в реализации.
1) Середину списка ищем медленным и быстрым указателями. Быстрый идёт в два раза быстрее, поэтому когда он дойдёт до конца, медленный окажется на середине.
2) Потом ещё одним циклом ищем узел перед серединой и ставим ему next = null, чтобы разорвать список на две половины, иначе рекурсия будет крутиться бесконечно.
3) Рекурсивно сортируем обе половины и сливаем их рекурсивной функцией mergeTwoLists.

Tracing
-1 -> 5 -> 3 -> 4 -> 0
Середина 3, делим на -1 -> 5 и 3 -> 4 -> 0.
-1 -> 5 делится на -1 и 5, слияние даёт -1 -> 5.
3 -> 4 -> 0 делится на 3 и 4 -> 0, 4 -> 0 сортируется в 0 -> 4, слияние даёт 0 -> 3 -> 4.
Слияние -1 -> 5 и 0 -> 3 -> 4 даёт -1 -> 0 -> 3 -> 4 -> 5.

Challenges
Список обязательно нужно разорвать посередине, иначе левая половина продолжает указывать на правую.

3. Time Complexity
Time Complexity: O(n log n)

T(n) = 2T(n/2) + n. Будет log n уровней рекурсии, и на каждом выполняется O(n) работы: поиск середины и слияние.

4. Space Complexity
Space Complexity: O(n)

Новых узлов не создаём, но mergeTwoLists рекурсивный, и его глубина может дойти до длины сливаемых списков. У самой сортировки глубина O(log n).

5. Reflection / Improvement
1) Сделать mergeTwoLists итеративным, чтобы не упереться в глубину рекурсии.
2) Не проходить список второй раз, чтобы найти узел перед серединой, а запоминать его прямо во время прохода медленным и быстрым указателями.
