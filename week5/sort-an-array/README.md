Sort an Array

1. Problem
Дан массив из n чисел. Нужно вернуть его отсортированным по возрастанию.

2. Approach
Обычный рекурсивный merge sort.
1) Базовый случай: если в массиве 0 или 1 элемент, возвращаем его как есть.
2) Делим массив пополам через Arrays.copyOfRange.
3) Рекурсивно сортируем левую и правую половину.
4) Сливаем их функцией merge: двумя указателями берём меньший элемент из двух половин, а в конце докидываем остаток той половины, где элементы ещё остались.

Tracing
[5, 2, 3, 1]
Делим на [5, 2] и [3, 1], потом на [5], [2], [3], [1].
merge([5], [2]) = [2, 5], merge([3], [1]) = [1, 3].
merge([2, 5], [1, 3]) = [1, 2, 3, 5].

Challenges
После основного цикла в merge нужно докинуть хвост той половины, где ещё остались элементы, иначе они потеряются.

3. Time Complexity
Time Complexity: O(n log n)

T(n) = 2T(n/2) + n. Глубина рекурсии log n уровней, и на каждом уровне все слияния вместе обрабатывают n элементов.

4. Space Complexity
Space Complexity: O(n)

Создаются копии половин и массив результата слияния, плюс O(log n) на стек рекурсии.

5. Reflection / Improvement
Это оптимальная сложность для сортировки сравнениями. merge сделан циклом, поэтому глубина рекурсии только O(log n). Можно не создавать копии половин на каждом уровне, а использовать один вспомогательный массив и передавать индексы.
