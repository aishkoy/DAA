Invert Binary Tree

1. Problem
Дан корень бинарного дерева. Нужно отзеркалить дерево: у каждого узла поменять местами левое и правое поддерево.

2. Approach
1) Если root == null, возвращаем null.
2) Меняем местами root.left и root.right через временную переменную.
3) Вызываем invertTree для левого и правого поддерева.
4) Возвращаем root.

Tracing
root = [4, 2, 7, 1, 3, 6, 9]
В узле 4 меняем местами 2 и 7.
В узле 7 меняем 6 и 9, в узле 2 меняем 1 и 3.
У листьев меняются местами два null.
Результат: [4, 7, 2, 9, 6, 3, 1].

Challenges
Сначала меняем детей местами, а потом рекурсивно разворачиваем их. Можно и в обратном порядке, результат будет тот же.

3. Time Complexity
Time Complexity: O(n)

Нужно посетить все узлы.

4. Space Complexity
Space Complexity: O(h), где h - высота дерева

Дерево меняется на месте, память уходит только на стек рекурсии.

5. Reflection / Improvement
По времени это оптимальное решение.
