Binary Tree Preorder Traversal

1. Problem
Дан корень бинарного дерева. Нужно обойти дерево в порядке preorder (узел, левое поддерево, правое поддерево) и вернуть список значений.

2. Approach
1) Создаём список result.
2) Вызываем вспомогательную функцию helper с корнем и result.
3) В helper, если узел не null, добавляем значение узла в result, потом вызываем helper для левого поддерева, потом для правого.
4) Возвращаем result.

Tracing
root = [1, null, 2, 3]: у 1 правый ребёнок 2, у 2 левый ребёнок 3.
helper(1): добавляем 1, левого нет, идём в helper(2).
helper(2): добавляем 2, идём в helper(3), добавляем 3.
Результат: [1, 2, 3].

Challenges
От inorder и postorder отличается только тем, в какой момент узел добавляется в список.

3. Time Complexity
Time Complexity: O(n)

Каждый узел посещается ровно один раз.

4. Space Complexity
Space Complexity: O(h), где h - высота дерева, не считая ответа

Это глубина стека рекурсии, в худшем случае h = n.

5. Reflection / Improvement
Это оптимальное решение, но обход можно сделать итеративно, используя стек вместо стека рекурсивных вызовов.
