Binary Tree Paths

1. Problem
Дан корень бинарного дерева. Нужно вернуть все пути от корня до листьев в виде строк вида "1->2->5".

2. Approach
1) Создаём пустой список result.
2) Вызываем вспомогательную функцию helper для корня с пустой строкой path.
3) helper добавляет значение узла к path.
4) Если узел - лист, path готов, кладём его в result.
5) Иначе добавляем "->" и вызываем helper для левого и правого поддерева.

Tracing
root = [1, 2, 3, null, 5]: у 1 дети 2 и 3, у 2 правый ребёнок 5.
helper(1, ""): path = "1->".
helper(2, "1->"): path = "1->2->", helper(5, "1->2->"): лист, добавляем "1->2->5".
helper(3, "1->"): лист, добавляем "1->3".
Ответ: ["1->2->5", "1->3"].

Challenges
Строки в Java неизменяемые, поэтому у каждой ветки своя копия пути и ничего не нужно откатывать после возврата из рекурсии.

3. Time Complexity
Time Complexity: O(n)

Посещаем все узлы. Если учитывать склейку строк, то в худшем случае O(n * h), потому что путь копируется на каждом уровне.

4. Space Complexity
Space Complexity: O(h)

Стек рекурсии и текущий путь, не считая ответа.

5. Reflection / Improvement
Это оптимальное решение. Склейку строк можно ускорить через StringBuilder, но тогда после возврата из рекурсии нужно обрезать его обратно.
