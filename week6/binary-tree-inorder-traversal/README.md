Binary Tree Inorder Traversal

1. Problem
Дан корень бинарного дерева. Нужно обойти дерево в порядке inorder (левое поддерево, узел, правое поддерево) и вернуть список значений.

2. Approach
1) Создаём список result.
2) Вызываем вспомогательную функцию helper с корнем и result.
3) В helper, если узел не null, вызываем helper для левого поддерева, потом добавляем значение узла в result, потом вызываем helper для правого поддерева.
4) Возвращаем result.

Tracing
root = [1, null, 2, 3]: у 1 правый ребёнок 2, у 2 левый ребёнок 3.
helper(1): левого нет, добавляем 1, идём в helper(2).
helper(2): идём в helper(3), добавляем 3, потом добавляем 2, правого нет.
Результат: [1, 3, 2].

Challenges
Во все рекурсивные вызовы передаётся один и тот же список result, а не создаётся новый.

3. Time Complexity
Time Complexity: O(n)

Каждый узел посещается ровно один раз.

4. Space Complexity
Space Complexity: O(h), где h - высота дерева, не считая ответа

Это глубина стека рекурсии, для вырожденного дерева h = n.

5. Reflection / Improvement
Это оптимальное решение, но обход можно сделать итеративно, используя стек вместо стека рекурсивных вызовов.
