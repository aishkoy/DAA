Minimum Depth of Binary Tree

1. Problem
Дан корень бинарного дерева. Нужно найти минимальную глубину - число узлов на кратчайшем пути от корня до листа.

2. Approach
1) Если root == null, глубина 0.
2) Если левого ребёнка нет, возвращаем minDepth(root.right) + 1.
3) Если правого ребёнка нет, возвращаем minDepth(root.left) + 1.
4) Если оба есть, возвращаем min(minDepth(left), minDepth(right)) + 1.
Проверки 2 и 3 нужны, потому что когда у узла один ребёнок, отсутствующая ветка дала бы глубину 0, и второе поддерево проигнорировалось бы.

Tracing
root = [2, null, 3, null, 4]: у 2 правый ребёнок 3, у 3 правый ребёнок 4.
minDepth(4) = 1.
minDepth(3): левого нет, minDepth(4) + 1 = 2.
minDepth(2): левого нет, minDepth(3) + 1 = 3.
Без проверки на одного ребёнка получилось бы min(0, ...) + 1 = 1, что неверно.

Challenges
Случай с одним ребёнком: пустая ветка - это не лист.

3. Time Complexity
Time Complexity: O(n)

В худшем случае посещаем все узлы.

4. Space Complexity
Space Complexity: O(h), где h - высота дерева

Стек рекурсии.

5. Reflection / Improvement
Поиск в глубину всегда доходит до всех листьев, даже если короткий путь найден рано. Можно использовать поиск в ширину (BFS) с очередью - он остановится на первом найденном листе.
