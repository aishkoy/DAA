Sum of Left Leaves

1. Problem
Дан корень бинарного дерева. Нужно найти сумму всех левых листьев, то есть листьев, которые являются левым ребёнком своего родителя.

2. Approach
1) Если root == null, возвращаем 0.
2) Каждый узел проверяет своего левого ребёнка: если он есть и у него нет детей, это левый лист, добавляем его значение.
3) Дальше прибавляем сумму левых листьев левого и правого поддерева.

Tracing
root = [3, 9, 20, null, null, 15, 7]
Узел 3: левый ребёнок 9 - лист, +9.
Узел 20: левый ребёнок 15 - лист, +15.
7 - правый лист, не считаем.
Ответ: 24.

Challenges
Сам лист не знает, левый он или правый, поэтому проверка делается из родителя.

3. Time Complexity
Time Complexity: O(n)

Посещаем каждый узел.

4. Space Complexity
Space Complexity: O(h), где h - высота дерева

Стек рекурсии.

5. Reflection / Improvement
Это оптимальное решение. Дополнительный флаг, левый ли узел, не нужен, потому что родитель сам проверяет своего левого ребёнка.
