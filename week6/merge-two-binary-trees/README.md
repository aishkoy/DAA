Merge Two Binary Trees

1. Problem
Даны два бинарных дерева root1 и root2. Если наложить одно дерево на другое, часть узлов совпадёт, а часть нет. Нужно слить деревья в одно: если два узла накладываются, значение узла - сумма их значений, иначе берётся тот узел, который не null. Нужно вернуть слитое дерево.

2. Approach
Второе дерево сливается прямо в первое, новые узлы не создаются.
1) Если root1 == null, возвращаем root2. Если root2 == null, возвращаем root1.
2) Если оба узла есть, root1.val = root1.val + root2.val.
3) root1.left = mergeTrees(root1.left, root2.left), root1.right = mergeTrees(root1.right, root2.right).
4) Возвращаем root1.

Tracing
root1 = [1, 3, 2, 5], root2 = [2, 1, 3, null, 4, null, 7]
Корни: 1 + 2 = 3.
Левые дети: 3 + 1 = 4. Правые дети: 2 + 3 = 5.
У 5 нет пары, остаётся 5. У 4 и 7 нет пары в первом дереве, их поддеревья просто подставляются.
Результат: [3, 4, 5, 5, 4, null, 7].

Challenges
Когда одного узла нет, глубже идти не нужно - сразу возвращается всё поддерево другого дерева.

3. Time Complexity
Time Complexity: O(min(n, m))

Как только одно из поддеревьев становится null, возвращаем другое, поэтому проходим только общую часть деревьев.

4. Space Complexity
Space Complexity: O(min(h1, h2))

Только стек рекурсии, новых узлов не создаём.
