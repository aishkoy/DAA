Path Sum

1. Problem
Дан корень бинарного дерева и число targetSum. Нужно проверить, есть ли путь от корня до листа, сумма узлов на котором равна targetSum.

2. Approach
1) В пустом поддереве такой суммы быть не может, возвращаем false.
2) Если узел - лист, ответ true, только если root.val == targetSum.
3) Иначе хотя бы в одном из поддеревьев должен быть путь с суммой targetSum - root.val.

Tracing
root = [5, 4, 8, 11, null, 13, 4, 7, 2, null, null, null, 1], targetSum = 22
Узел 5: ищем 17 в поддеревьях.
Узел 4: ищем 13.
Узел 11: ищем 2.
Лист 7: 7 != 2, false. Лист 2: 2 == 2, true.
Путь 5 -> 4 -> 11 -> 2.

Challenges
Сумма проверяется только в листе. Если бы проверка была на null, узел с одним ребёнком дал бы ложный путь.

3. Time Complexity
Time Complexity: O(n)

В худшем случае посещаем все узлы.

4. Space Complexity
Space Complexity: O(h), где h - высота дерева
