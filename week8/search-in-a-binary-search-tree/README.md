Search in a Binary Search Tree

1. Problem
Дан корень дерева поиска (BST) и число val. Нужно найти узел со значением val и вернуть поддерево с корнем в этом узле. Если такого узла нет, вернуть null.

2. Approach
Это бинарный поиск, только по дереву, сделан циклом:
1) Начинаем с корня.
2) Если val меньше значения узла, идём налево, если больше - направо.
3) Останавливаемся, когда нашли узел с val или дошли до null, и возвращаем текущий узел.

Tracing
root = [4, 2, 7, 1, 3], val = 2
curr = 4: 2 < 4, идём налево.
curr = 2: 2 == 2, нашли.
Возвращаем поддерево [2, 1, 3].

Challenges
Возвращается сам узел, а не его значение, тогда вместе с ним возвращается и всё его поддерево.

3. Time Complexity
Time Complexity: O(h), где h - высота дерева

На каждом шаге спускаемся на один уровень: для сбалансированного дерева O(log n), для вырожденного O(n).

4. Space Complexity
Space Complexity: O(1)

Цикл использует только один указатель, стека рекурсии нет.

5. Reflection / Improvement
Это оптимальное решение: быстрее, чем пройти один путь от корня вниз, узел не найти.
