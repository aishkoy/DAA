Search in a Binary Search Tree

1. Problem
Дан корень дерева поиска (BST) и число val. Нужно найти узел, у которого значение равно val, и вернуть его вместе со всем его поддеревом. Если такого узла нет, вернуть null.

2. Approach
В BST у каждого узла все значения слева меньше него, а справа больше. Поэтому не нужно обходить всё дерево, достаточно на каждом шаге выбрать одну сторону.
1) Если узел null, значит дошли до конца ветки и такого значения нет, возвращаем null.
2) Если значение узла равно val, возвращаем этот узел.
3) Если val меньше значения узла, рекурсивно ищем в левом поддереве.
4) Иначе рекурсивно ищем в правом поддереве.

Tracing
Пример 1: root = [4, 2, 7, 1, 3], val = 2
Вызов searchBST(4): 2 < 4, идём в левое поддерево.
Вызов searchBST(2): 2 == 2, нашли, возвращаем узел 2.
Ответ: поддерево [2, 1, 3].

Пример 2: root = [4, 2, 7, 1, 3], val = 5
Вызов searchBST(4): 5 > 4, идём направо.
Вызов searchBST(7): 5 < 7, идём налево.
Вызов searchBST(null): возвращаем null.
Ответ: null.

Challenges
Сначала думала просто обойти всё дерево любым обходом и проверять каждый узел. Это работает, но тогда не используется то, что дерево BST, и в худшем случае посещаются все n узлов. Сравнение val со значением узла позволяет сразу отбросить половину, в которой ответа быть не может.
Ещё нужно возвращать сам узел, а не его значение: по условию ответ - это поддерево, а узел уже содержит ссылки на своих детей.
Проверяла на значении, которое есть в дереве (2), и на значении, которого нет (5).

3. Time Complexity
Time Complexity: O(h), где h - высота дерева

На каждом вызове спускаемся на один уровень вниз и в другую сторону уже не возвращаемся, поэтому вызовов не больше, чем высота дерева. Для сбалансированного дерева h = log n, для вырожденного (все узлы в одну линию) h = n.

4. Space Complexity
Space Complexity: O(h)

Решение рекурсивное, и каждый вызов лежит в стеке, пока не вернётся ответ. Глубина стека равна длине пройденного пути, то есть не больше h.

5. Reflection / Improvement
По времени лучше O(h) не сделать, но можно улучшить память. Рекурсию можно заменить циклом while: держать указатель curr и двигать его налево или направо, пока не найдём val или не дойдём до null. Время останется O(h), а память станет O(1), потому что стек рекурсии не нужен.
