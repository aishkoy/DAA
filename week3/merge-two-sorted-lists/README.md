Merge Two Sorted Lists

1. Problem
Даны два отсортированных односвязных списка. Нужно слить их в один отсортированный список.

2. Approach
Это решение я не придумала сама. Как оно работает:
1) Если list1 или list2 равен null, возвращаем другой список.
2) Решаем рекурсивно: каждый вызов берёт меньший из двух узлов (например, list1), а его next ставит на результат рекурсивного вызова с list1.next и list2.
3) В итоге, после всех вызовов, два списка сливаются в один.

Tracing
list1 = 1 -> 2 -> 4, list2 = 1 -> 3 -> 4
Вызов 1: 1 и 1, берём list1 (1 <= 1).
Вызов 2: 2 и 1, берём list2.
Вызов 3: 2 и 3, берём list1.
Вызов 4: 4 и 3, берём list2.
Вызов 5: 4 и 4, берём list1.
Вызов 6: list1 = null, возвращаем list2.
Результат: 1 -> 1 -> 2 -> 3 -> 4 -> 4.

Challenges
Главная идея - хвост результата это слияние оставшихся частей, то есть та же задача, только поменьше.

3. Time Complexity
Time Complexity: O(n + m), где n и m - длины list1 и list2

Каждый рекурсивный вызов уменьшает один из списков на один элемент, поэтому функция вызывается для каждого элемента обоих списков. Если один из списков изначально пустой, то O(1).

4. Space Complexity
Space Complexity: O(n + m)

Новых узлов не создаём, но глубина рекурсии может дойти до n + m.

5. Reflection / Improvement
На очень длинных списках рекурсия может закончиться StackOverflowError. Лучше сливать списки итеративно, тогда память будет O(1).
