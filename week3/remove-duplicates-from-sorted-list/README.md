Remove Duplicates from Sorted List

1. Problem
Дан отсортированный односвязный список. Нужно удалить дубликаты, чтобы каждое значение встречалось один раз.

2. Approach
Идём указателем curr и сравниваем его с curr.next.
Если значения одинаковые, перекидываем указатель через следующий узел: curr.next = curr.next.next.
Если разные, двигаем curr на один узел вперёд.
Продолжаем, пока curr или curr.next не станет null, и возвращаем head.

Tracing
1 -> 1 -> 2 -> 3 -> 3
curr = 1, next = 1: удаляем, список 1 -> 2 -> 3 -> 3.
curr = 1, next = 2: двигаем.
curr = 2, next = 3: двигаем.
curr = 3, next = 3: удаляем, список 1 -> 2 -> 3.
curr = 3, next = null: конец.

Challenges
После удаления дубликата curr не двигаем, потому что следующий узел тоже может быть дубликатом.

3. Time Complexity
Time Complexity: O(n)

Список проходится один раз.

4. Space Complexity
Space Complexity: O(1)

Меняем указатели прямо в списке, нужна только одна переменная.

5. Reflection / Improvement
Это оптимальное решение. Были проблемы со стилем кода и лишним кодом, но сам алгоритм был тот же, потом отрефакторила с помощью ИИ.
