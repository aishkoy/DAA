Palindrome Linked List

1. Problem
Дан односвязный список. Нужно определить, является ли он палиндромом.

2. Approach
1) Создаём ArrayList для значений списка.
2) Проходим список и складываем значения в ArrayList.
3) Ставим два указателя на концы: start = 0, end = arr.size() - 1.
4) Двигаем их к середине и на каждом шаге сравниваем значения.
5) Если значения разные, возвращаем false. Иначе в конце возвращаем true.

Tracing
1 -> 2 -> 2 -> 1, arr = [1, 2, 2, 1]
start = 0, end = 3: 1 и 1, равны.
start = 1, end = 2: 2 и 2, равны.
Указатели встретились, ответ true.

Challenges
В List<Integer> лежат объекты, поэтому значения сравниваются через equals, а не ==. Для чисел больше 127 == сравнивал бы ссылки и вернул бы false.

3. Time Complexity
Time Complexity: O(n)

Один проход по списку и половина массива двумя указателями.

4. Space Complexity
Space Complexity: O(n)

Массив хранит все значения списка.

5. Reflection / Improvement
Есть решение с O(1) памяти. Середину списка можно найти быстрым и медленным указателями: быстрый идёт в два раза быстрее, поэтому когда он дойдёт до конца, медленный окажется ровно посередине. Потом разворачиваем вторую половину и идём по обеим половинам двумя указателями.
