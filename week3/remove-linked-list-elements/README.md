Remove Linked List Elements

1. Problem
Дана голова односвязного списка и число val. Нужно удалить из списка все узлы со значением val.

2. Approach
Идём по списку, и если у следующего узла значение val, ставим curr.next = curr.next.next, так узел удаляется. Иначе двигаем curr дальше.
Крайний случай: если удалить нужно саму голову, такой алгоритм не сработает, потому что он проверяет только curr.next. Поэтому создаём фиктивный узел dummy, который указывает на head, и начинаем с него. В конце возвращаем dummy.next.

Tracing
6 -> 1 -> 2 -> 6 -> 3 -> 6, val = 6, перед головой dummy
curr = dummy, next = 6: удаляем.
curr = dummy, next = 1: двигаем.
curr = 1, next = 2: двигаем.
curr = 2, next = 6: удаляем.
curr = 2, next = 3: двигаем.
curr = 3, next = 6: удаляем.
curr = 3, next = null: конец.
Результат: 1 -> 2 -> 3.

Challenges
Удаление головы списка, его решает dummy.

3. Time Complexity
Time Complexity: O(n)

В худшем случае удалить нужно узел в самом конце, и проходим весь список.

4. Space Complexity
Space Complexity: O(1)

Кроме одного фиктивного узла и указателя ничего не нужно.

5. Reflection / Improvement
Решение оптимальное. Мне очень понравился приём с фиктивным узлом.
